# User Flows — CotaCerta

## Gestor cria caixinha

1. Acessa o sistema.
2. Clica em criar caixinha.
3. Informa nome, ano, valor da cota e dia de vencimento.
4. Salva.
5. Sistema exibe a caixinha na lista.

## Gestor cadastra cotista

1. Entra na caixinha.
2. Clica em adicionar cotista.
3. Informa nome, telefone e chave Pix opcional.
4. Define 1 ou 2 cotas.
5. Salva.

## Gestor gera cobrança mensal

1. Entra na caixinha.
2. Seleciona o mês.
3. Sistema gera cobranças para cotistas ativos.
4. Sistema calcula valor conforme quantidade de cotas.

## Gestor registra pagamento Pix

1. Entra na caixinha.
2. Localiza cotista.
3. Seleciona cobrança.
4. Informa valor pago.
5. Anexa comprovante.
6. Confirma pagamento.

## Gestor vê quem deve

1. Entra na caixinha.
2. Abre tela Quem Deve.
3. Sistema lista cotistas pendentes.
4. Gestor pode gerar mensagem de cobrança.

## Cotista acessa painel

1. Recebe convite.
2. Cria acesso.
3. Visualiza suas caixinhas.
4. Visualiza cotas, pagamentos e pendências.

## Fechamento anual

1. Gestor abre fechamento.
2. Sistema calcula total disponível.
3. Sistema desconta dívidas.
4. Sistema calcula valor por cota.
5. Sistema mostra valor por cotista.
6. Gestor confirma fechamento.
