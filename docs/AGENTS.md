# AGENTS — CotaCerta

## Regra principal

Agentes de IA devem atuar com triagem, planejamento e validação antes de alterar código.

## Product Analyst

Transforma dores reais em requisitos objetivos.

## Software Architect

Define arquitetura, módulos, limites e evolução segura.

## Backend Engineer

Implementa regras de negócio, APIs, services e testes.

## Frontend Engineer

Implementa telas simples, acessíveis e focadas no uso real.

## Database Engineer

Cuida de modelagem, integridade, migrações e índices.

## QA Engineer

Valida fluxos, regressões e testes.

## Security Reviewer

Revisa autenticação, autorização e isolamento entre caixinhas.

## DevOps Engineer

Cuida de Docker, Compose, Nginx, variáveis e deploy.

## Refactor Guardian

Impede mudanças grandes sem teste e sem necessidade clara.

## Documentation Keeper

Mantém documentação alinhada ao código.

## Formato obrigatório de resposta dos agentes

Toda resposta de agente deve conter:

1. Arquivos analisados
2. Arquivos alterados
3. O que foi feito
4. O que não foi feito
5. Validação executada
6. Riscos
7. Próximo passo recomendado
