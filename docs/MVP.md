# MVP — CotaCerta

## Objetivo

Permitir que o Gestor Master abandone o controle em papel e consiga controlar caixinhas, cotistas, pagamentos Pix, comprovantes e quem está devendo.

## Funcionalidades obrigatórias

- login do gestor;
- criação de caixinha;
- cadastro de cotistas;
- definição de 1 ou 2 cotas por cotista;
- geração de cobrança mensal;
- registro de pagamento Pix;
- anexo de comprovante;
- tela de quem deve;
- mensagem de cobrança por WhatsApp;
- painel simples do cotista;
- registro de empréstimo para cotista;
- cálculo de juros de 30%;
- fechamento anual simples.

## Funcionalidades adiadas

- OCR/IA para leitura automática de comprovantes;
- integração bancária;
- WhatsApp API oficial;
- subgestores;
- permissões avançadas;
- app mobile nativo.

## Critérios de sucesso

O MVP será considerado útil se o gestor conseguir:

1. cadastrar uma caixinha;
2. cadastrar 10 cotistas;
3. definir quem tem 1 ou 2 cotas;
4. gerar cobranças mensais;
5. registrar Pix recebido;
6. anexar comprovante;
7. ver quem deve;
8. cobrar pelo WhatsApp;
9. registrar empréstimo com juros;
10. calcular uma divisão anual simples.

## Riscos

- excesso de funcionalidades no início;
- tentar automatizar comprovante antes da base estar pronta;
- linguagem técnica demais;
- falta de auditoria financeira;
- mistura de dados entre caixinhas.
